# figuren

Hier entstehen die Bausteine-Abbildungen des Buchs (Steine, Türme, Bauplatten), als SVG in `Bilder/figuren/`.
Neu bauen: `python3 figuren/build.py`; prüfen: `python3 -m unittest discover figuren`, `python3 figuren/check_qmd.py`, `python3 figuren/check_sections.py`.
Was in die Bilder gehört und wie sie aussehen, regelt `BILDER.md`.
